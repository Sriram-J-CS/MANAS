1. EXECUTIVE SYSTEM OVERVIEW
================================================================================
MANAS is an emotionally intelligent, culturally native 3D AI Digital Mental Twin
and wellness companion designed for India's linguistic diversity. It features:
- Real-time 3D humanoid WebGL avatar with procedural micro-animations and lip-sync.
- 8 Indian languages (Tamil, Telugu, Hindi, Kannada, Malayalam, Bengali, Marathi,
  and English) with authentic colloquial vernacular fluency.
- Acoustically segregated voice synthesis with Sarvam Bulbul v3.
- Professional speech-to-text via Sarvam Saaras v3 with server proxy and VAD.
- Ultrafast Gemini 3.8 Flash streaming with hidden diagnostic analysis (<= 60 tokens),
  concrete detail reflection (100%), and anti-repetition (< 0.60 similarity).
- Hybrid vector memory (768-dim embeddings) and per-user style profile adaptation.
- Supabase Auth (Phone OTP, Email/Password, and Guest "Skip for now") with RLS.

3. 3D WEBGL HUMANOID AVATAR & PROCEDURAL GRAPHICS ENGINE

- WHERE: frontend/src/components/avatar/VRMAvatarCanvas.tsx,
  frontend/src/components/RealMascot.tsx, frontend/src/components/MascotStage.tsx

3.2 @pixiv/three-vrm (^3.5.5)
- WHAT: Specification and runtime loader for VRM 1.0 humanoid 3D avatars.
- WHERE: frontend/src/components/avatar/VRMAvatarCanvas.tsx
- HOW: Loads VRM avatar models (.vrm), binds humanoid skeleton bones (neck, head,
  spine, arms, hands), and manipulates blend shape morph targets in real time.

3.3 Emotive Visemes & Facial Morph Targets
- WHAT: Morph targets conforming to VRM expression specifications.
- WHERE: frontend/src/lib/avatar/visemeMapper.ts, VRMAvatarCanvas.tsx
- HOW: Maps spoken phonemes/frequencies to Japanese/Latin visemes:
  - Vowels: 'aa', 'ih', 'ou', 'ee', 'oh'
  - Emotional expressions: 'happy', 'angry', 'sad', 'surprised', 'relaxed', 'neutral'
  - Blinking: 'blink', 'blinkLeft', 'blinkRight'

3.4 Procedural Body Mechanics & Animation Loop
- WHAT: Mathematical sine-wave procedural movements.
- WHERE: VRMAvatarCanvas.tsx
- HOW: Simulates natural human breathing by oscillating spine/chest bones,
  implements autonomous blinking intervals (every 3-5 seconds), head-tilting
  towards the user cursor, and arm waving greetings on companion selection.

3.5 GPU Starvation Protection & DPR Capping
- WHAT: Canvas rendering throttling to prevent main-thread lag.
- WHERE: frontend/src/components/avatar/VRMAvatarCanvas.tsx
- HOW: Device Pixel Ratio is strictly capped at min(window.devicePixelRatio, 2.0).
  Lip-sync FFT analysis is throttled to <= 30 Hz (33.3 ms intervals), preventing
  WebGL rendering from starving the audio decode/playback thread.

4. MULTILINGUAL TEXT-TO-SPEECH (TTS) & ACOUSTIC PIPELINE
================================================================================

4.1 Sarvam Bulbul v3 API
- WHAT: Indian vernacular Text-to-Speech deep learning model ("bulbul:v3").
- WHERE: backend/app/services/sarvam_tts.py, backend/app/services/voice_config.py
- HOW: Accepts native script Unicode text, sample rate (24000 Hz), speaker ID,
  and pace. Synthesizes high-fidelity audio chunks across 8 languages.

4.2 Distinct Speaker Matrix & Acoustic Segregation
- WHAT: Segregated voice profiles ensuring every tone card sounds distinctly different.
- WHERE: backend/app/services/voice_config.py
- HOW:
  - Female Companion (Pitch > 170 Hz):
    * Ananya -> priya (pace 1.00)
    * Diya   -> ishita (pace 0.93)
    * Meera  -> ritu / neha / pooja / roopa / suhani (pace 1.05)
  - Male Companion (Pitch < 165 Hz):
    * Aarav  -> shubh (pace 0.93)
    * Kabir  -> ratan (pace 1.00)
    * Arjun  -> rohan / rehan (pace 1.05)
  All tone cards produce distinct byte streams and pitch differences (|ΔF0| >= 14 Hz).

4.3 Web Audio Gapless Buffer Scheduling
- WHAT: Precise scheduling using AudioContext.currentTime.
- WHERE: frontend/src/components/ChatCompanionModal.tsx,
  frontend/src/lib/audio/sharedAudioContext.ts
- HOW: Creates AudioContext at fixed 24,000 Hz matching backend audio. Decodes
  chunks ahead of time using decodeAudioData. Schedules chunks gaplessly using:
  startTime = Math.max(audioContext.currentTime, nextStartTime).
  Parallel prefetching loads chunks 1-2 ahead while chunk 0 is actively playing.

4.4 Text Pre-processing & Pronunciation Normalization
- WHAT: Native script cleaner and expander.
- WHERE: backend/app/services/sarvam_tts.py (normalize_text_for_speech)
- HOW:
  - Expands numbers, dates, units, abbreviations into target native language
    (e.g., "5 mins" -> "5 minutes" or "5 நிமிடங்கள்", "%" -> "percent" or "प्रतिशत").
  - Strips Markdown bold, code backticks, URLs, emojis, and symbols.
  - Retains native Indic scripts (Tamil, Telugu, Devanagari, Bengali, Kannada, Malayalam).
  - Normalizes multiple punctuation into clean acoustic pause marks.

4.5 Native Indic Fallback Engine (Google Cloud Chirp 3 HD)
- WHAT: High-definition native fallback for TTS timeouts.
- WHERE: backend/app/services/sarvam_tts.py (_synthesize_chirp3_hd_fallback)
- HOW: Strictly routes to native Indic Chirp 3 HD models (e.g., ta-IN-Chirp3-HD-F,
  hi-IN-Chirp3-HD-M). Strict rule: NEVER switches to an English voice.

5. PROFESSIONAL SPEECH-TO-TEXT (STT) & AUDIO INGESTION
================================================================================

5.1 Sarvam Saaras v3 API
- WHAT: State-of-the-art Indian language speech-to-text ("saaras:v3").
- WHERE: backend/app/services/sarvam_stt.py, backend/app/main.py
- HOW:
  - REST endpoint: POST /api/voice/stt for short utterances (<= 30 s).
  - WebSocket proxy: /api/voice/stt/ws -> wss://api.sarvam.ai/v1/stt/stream
    (16 kHz mono 16-bit PCM WAV).
  - Secure Server Proxy: API keys are strictly server-side; browser connects
    only to MANAS backend with JWT verification and rate limiting.

5.2 Client Voice Activity Detection (VAD) & MediaStream Audio
- WHAT: On-device microphone stream management with speech boundaries.
- WHERE: frontend/src/components/ChatCompanionModal.tsx
- HOW:
  - navigator.mediaDevices.getUserMedia with echoCancellation: true,
    noiseSuppression: true, autoGainControl: true.
  - VAD cuts utterances after 1.2s - 1.5s of consecutive silence.
  - Automatically pauses listening while companion is speaking to eliminate
    acoustic feedback loops.

5.3 Transcription Modes & Code-Mixing
- WHAT: Native transcription and bilingual codemix handling.
- WHERE: backend/app/services/sarvam_stt.py
- HOW:
  - 'transcribe' mode generates pure native Indic script.
  - 'codemix' mode preserves English words intermingled in vernacular speech.
  - Automatic language detection fallback offers switch prompt (e.g. "Switch to Tamil?").
  - Empty or low-confidence results trigger empathetic clarification:
    "I didn't catch that, could you please repeat?"

5.4 Mic Controls: Push-to-Talk vs Hands-Free
- WHAT: Conversational microphone toggle.
- WHERE: frontend/src/components/ChatCompanionModal.tsx
- HOW: Provides a one-line setting allowing users to toggle between continuous
  VAD-driven hands-free conversation and manual push-to-talk.

6. LLM ORCHESTRATION, STREAMING & DIAGNOSTIC REASONING
================================================================================

6.1 Google Gemini 3.8 Flash
- WHAT: Fast multimodal foundation model with low-latency streaming.
- WHERE: backend/app/services/gemini_provider.py
- HOW: Model configuration: gemini-3.8-flash with thinking LOW. Pipelined in
  parallel with memory search and safety classification. Delivers tokens to UI
  in ~986 ms (TTFT p50).

6.2 Hidden Diagnostic Clinical Analysis (<= 60 Tokens)
- WHAT: Real-time psychological telemetry prepended to model generation.
- WHERE: backend/app/services/gemini_provider.py (get_structured_output_schema)
- HOW: Output structure begins with a hidden JSON diagnostic object:
  {
    "mood": "anxious" | "sad" | "overwhelmed" | "angry" | "happy" | "neutral",
    "intensity": 1-5,
    "need": "grounding" | "validation" | "vent" | "advice" | "company",
    "key_details": ["midterms", "organic chemistry"],
    "language": "en",
    "risk": "none" | "low" | "medium" | "high"
  }
  Followed by the spoken reply. The backend strips the analysis from the client
  reply stream and logs it asynchronously to the database for mood tracking.

6.3 Concrete Detail Reflection (100% Hit Rate)
- WHAT: Natural linguistic echoing of user-specific entities.
- WHERE: backend/app/services/gemini_provider.py,
  backend/app/services/autonomous_companion.py (extract_key_details)
- HOW: Extracts capitalized words, acronyms (C++, UPSC, Figma), numerical quantities
  (5000 rupees, 10,000 steps, 3:45 AM), and compound noun phrases. Mandates that
  the reply explicitly references at least one concrete detail from the user's message.

6.4 Anti-Repetition Engine (< 0.60 Similarity Target)
- WHAT: Algorithmic prevention of robotic or repetitive companion dialogue.
- WHERE: backend/app/services/embedding_service.py (is_too_similar, ngram_overlap_ratio)
- HOW:
  - Banned stock phrases list ("I understand how you feel", "take a deep breath", etc.).
  - Tracks last 5 reply openings as forbidden sentence structures.
  - Inspects first sentence against last 10 bot replies; if 5-gram overlap > 0.45 or
    cosine similarity > 0.70, regenerates once with higher temperature.
  - Achieved average pairwise similarity of 0.448 across 30 diverse benchmark inputs.

6.5 Mood-Adaptive Steering & Avatar Expression Coupling
- WHAT: Emotional conditioning governing tone, pace, and visuals.
- WHERE: backend/app/main.py, backend/app/services/gemini_provider.py
- HOW:
  - 'anxious'     -> Slow pace (0.90), grounding focus, gentle avatar gesture, 4-7-8 breathing.
  - 'sad/low'     -> Empathic presence, concise validation, quiet comfort expression.
  - 'angry'       -> Space and validation, zero unsolicited advice, listening posture.
  - 'overwhelmed' -> Problem de-escalation, maximum one gentle question at a time.
  - 'happy'       -> Celebrating and building upon user victories, excited avatar gestures.

7. MEMORY VECTORIZATION, STYLE PROFILING & PERSONALIZATION
================================================================================

7.1 Postgres + pgvector (768-Dimensional Embeddings)
- WHAT: Vector similarity search engine in PostgreSQL.
- WHERE: backend/schema_pgvector.sql, backend/app/services/embedding_service.py
- HOW: Uses text-embedding-004 to vectorize conversation memories into 768-dim floats.
  Hybrid retrieval combines cosine similarity (<=> operator) with exponential
  recency decay score: final_score = 0.7 * cosine_sim + 0.3 * recency_weight.
  Injects top 5 retrieved memories into prompt without fine-tuning.

7.2 Per-User Style Profile Matrix
- WHAT: Dynamic behavioral profile table updated asynchronously after each turn.
- WHERE: backend/app/database.py (user_style_profiles table)
- HOW: Stores:
  - preferred_reply_length ('short' | 'balanced' | 'detailed')
  - directness ('gentle' | 'direct')
  - humour ('none' | 'light' | 'witty')
  - language_mix ('pure' | 'colloquial' | 'codemix')
  - techniques_helped / techniques_unhelpful (fed by Helpful / Didn't feel understood buttons)
  - known_triggers and low_times_of_day
  Injected into Gemini system prompt alongside 2 past helpful replies and 1 unhelpful reply.

8. AUTHENTICATION, SECURITY & DATABASE ARCHITECTURE
================================================================================

8.1 Supabase Auth & Storage Isolation
- WHAT: Production identity provider with OAuth/JWT capabilities.
- WHERE: frontend/src/lib/supabase.ts, frontend/src/components/auth/AuthModal.tsx
- HOW:
  - Phone OTP Tab: E.164 (+91) format with single 'Send code' button, 60s cooldown.
  - Email & Password Tab: signUp, signInWithPassword, password recovery email.
  - Session Management: persistSession: true, autoRefreshToken: true.
  - Multi-User Isolation: On SIGNED_OUT or user switch, clears all local caches,
    sessionStorage, IndexedDB, and twin profiles.
  - Resilient Local Fallback (createLocalFallbackSession): Seamlessly falls back
    to test session if Supabase cloud is offline or unreachable.

8.2 Optional Sign-In & Anonymous Guest Session
- WHAT: Zero-friction mental health accessibility.
- WHERE: frontend/src/lib/supabase.ts (createAnonymousSession),
  frontend/src/components/auth/AuthModal.tsx
- HOW: Users can click 'Skip for now · Continue as Guest' to explore MANAS
  anonymously. Route guards permit anonymous guest sessions so distressed users
  are never blocked by an auth barrier.

8.3 PostgreSQL Triggers & Row-Level Security (RLS)
- WHAT: Database-enforced multi-tenant security.
- WHERE: supabase/migrations/002_profiles_trigger.sql
- HOW:
  - Trigger on auth.users INSERT automatically creates public.profiles(id, name,
    phone, email, created_at).
  - RLS policies restrict SELECT, UPDATE, DELETE to auth.uid() = id.
  - public.consents table logs timestamped privacy agreements.

8.4 On-Device & Server Zero-PII Cryptography
- WHAT: Cryptographic privacy shield.
- WHERE: backend/app/services/user_crypto.py
- HOW: AES-256-GCM authenticated encryption for all stored chat transcripts,
  memories, and journal notes. Every record uses a fresh 96-bit random IV and
  128-bit authentication tag.

9. BACKEND FASTAPI SERVICES & API ROUTING
================================================================================

9.1 FastAPI Framework & ASGI Uvicorn Server
- WHAT: High-performance asynchronous Python web framework.
- WHERE: backend/app/main.py, running on port 8008.
- HOW: Implements asynchronous endpoints for streaming chat (SSE), speech-to-text,
  text-to-speech, memory management, wellness logs, and crisis routing.

9.2 Key API Endpoints
- POST /api/chat/companion/stream
  Streaming SSE chat pipeline with Gemini 3.8 Flash, hybrid memory, and mood adaptation.
- POST /api/voice/tts
  Sarvam Bulbul v3 Text-to-Speech synthesis with 24000 Hz gapless chunk generation.
- POST /api/voice/stt & WebSocket /api/voice/stt/ws
  Sarvam Saaras v3 Speech-to-Text streaming with 16 kHz mono PCM proxy.
- GET  /api/health
  Health check returning server status, database state, and active AI models.
- GET  /api/domain/twin/overview
  Retrieves user style profile, emotional baseline, and recent wellness logs.
- POST /api/domain/wellness/log
  Logs user check-ins and heart rate / emotional telemetry.
