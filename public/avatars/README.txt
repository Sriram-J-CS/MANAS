# 3D Avatar Models Folder

Place your custom rigged GLB or VRM full-body characters here:
1. `boy.glb`: Stylized cartoon boy with short black messy hair, blue hoodie, warm brown eyes, ARKit blendshapes + visemes.
2. `girl.glb`: Stylized cartoon girl with long dark hair, yellow shirt, grey hoodie, warm brown eyes, ARKit blendshapes + visemes.

### Exporting from VRoid Studio (Free, Recommended):
1. Download VRoid Studio (Free on Steam / vroid.com).
2. Customize character features (hair, eyes, hoodie clothing).
3. Click Export -> Export as VRM (or use Blender VRM-to-GLTF plugin to export as GLB).
4. Ensure ARKit Blendshapes (A, I, U, E, O, Blink, Smile, Joy, Sorrow, Angry) are enabled.
5. Save as `boy.glb` / `girl.glb` in this folder.
